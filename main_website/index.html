A few things you might want to know before creating your gift.

Bisa dibuka di HP pasangan?

Bisa. Semua template responsif untuk HP, tablet, dan laptop.

Apa bedanya Website Code dan Canva?

Website Code dikerjakan kami dari materi yang kamu kirim, dan bisa interaktif. Template Canva bisa kamu edit sendiri kapan saja dan dibagikan lewat satu link.

Link aktif sampai kapan?

Lite dan Canva aktif selamanya. Silver dan Gold aktif 3 bulan. Mau permanen? Tambah Upgrade Lifetime (+Rp100.000) dan kamu dapat source code serta diajari deploy.

Lagunya bisa diganti?

Bisa. Musik sudah termasuk di paket Gold, dan bisa ditambah ke paket lain lewat add-on musik (+Rp5.000).

Berapa lama pengerjaannya?

Sekitar 2–3 hari kerja setelah pembayaran dan data lengkap. Butuh cepat? Rush (+Rp5.000) siap dalam 4–8 jam.
